### 1. Query Classification (Pre-Processing)
Function: `classify_query(query)`
- Classifies into: greeting, small_talk, question, unclear
- Detects intent: claims, plans, hospitals, coverage
- Routes queries appropriately BEFORE RAG
- Saves LLM tokens on non-questions

### 2. Page Context Integration
- Frontend sends `page_context` (bill-buster, get-quote, dashboard, home)
- Backend boosts relevant document scores by 15%
- Example: On bill-buster page → bill-related docs ranked higher
- Implemented in: chatbot_widget.js + retrieve() function

### 3. Intent-Based Retrieval Filtering
- Extracts intent from query (claims, plans, hospitals, coverage)
- Filters documents by metadata topics/keywords
- Boosts matching documents by 10%
- Re-ranks candidates after filtering

### 4. Suggested Questions
Function: `get_suggested_questions(page_context, intent)`
- Page-specific suggestions:
  - bill-buster: billing errors, negotiations, claim process
  - get-quote: premium factors, sum insured, deductibles
  - dashboard: claim filing, network hospitals, renewals
- Intent-specific suggestions:
  - claims: cashless, reimbursement, settlement time
  - plans: comparison, best for families, coverage needs
  - hospitals: network hospitals, cashless treatment

### 5. Improved Prompt Building
- Added user profile context block
- Better document formatting with metadata
- Conversation context (last 6 messages)
- Clear instruction section

### 6. Enhanced Metadata on Documents
All KB articles now include:
- `topics`: ["coverage", "claims", "plans", "hospitals"]
- `keywords`: Specific search terms
- `page_type`: "knowledge_base"
- `category`: Grouping (basics, claims, coverage, etc.)
